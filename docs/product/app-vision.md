# App vision

speca is an application for building software with coding agents. It helps users direct work and delegate development while staying involved where their input matters.

A workspace can contain ideas, requirements, designs, code, research, and other content. Users choose what belongs in the workspace and how to organize it. speca shows the workspace’s contents and their relationships.

Users work with agents through the workspace itself. They can open any part, describe a change, or leave a comment. Agents use the relevant workspace content, ask questions when needed, and propose changes.

Users choose where agents can act independently and where they must wait for review. Within those boundaries, agents make changes, check their work, and explain any differences between the intended result and what they produced.

When one part changes, related work may need updating. speca makes those dependencies visible so users and agents can see what is affected and decide what to update next.
