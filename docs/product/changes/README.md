# Changes

A change groups related edits in one [branch worktree](../version-control/branches.md). Users can propagate an initial edit whether they make it directly or apply it through a plan.

- [Planning](planning.md): proposals, questions, comments, and plan approval.
- [Propagation](propagation.md): triage, dependency ordering, and iteration history.
- [Entity refresh](entity-refresh.md): agent context, edits, results, and refresh approval.
