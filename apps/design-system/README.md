# Design system

- [Source](src/): components, styles, and stories.
- [Storybook configuration](.storybook/): catalog settings.
- [Tests](tests/): pattern checks.

## Run Storybook

Use Node.js 22.12 or newer. From the repository root:

```sh
cd apps/design-system
npm ci
npm run storybook
```

Open <http://localhost:6006>.
