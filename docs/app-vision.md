# App vision

speca is a workspace for building software with coding agents. It helps users direct a project and delegate development work while staying involved in the decisions that matter to them.

A project can contain anything the user wants: ideas, requirements, designs, code, research, or other content. Users choose what belongs in the project and how to organize it. The workspace shows its parts and the connections between them.

Users work with agents through the project itself. They can open any part, describe a change, or leave a comment. Agents use the relevant project content, ask questions when needed, and propose changes.

Users choose where agents can act independently and where they must wait for review. Within those boundaries, agents make changes, check their work, and explain any differences between the intended result and what they produced.

When one part changes, related work may need updating. speca makes those dependencies visible so users and agents can see what is affected and decide what to update next.

The project keeps a history of decisions and their reasons. Users can understand how it developed and review the work that needs their attention without reading every document or code change.
